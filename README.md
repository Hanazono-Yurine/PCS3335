# PCS3335 (2025)

## Sobre

Este repositório contém os "códigos" das atividades do Laboratório Digital(PCS3335)

Cada pasta contém a sua respectiva atividade, e na pasta `relatorios` você encontrará os relatorios 
das respectivas atividades separados por pasta, por mais estranho que pareça ;P

## Atividades

Esse ano, (2025), as tarefas se resumiam a fazer pequenas inplementações da UART 16550, para que
no final tivessemos uma UART completa

## Projeto Final

Foi decidido fazer um calculadora com [notação polonesa inversa](https://en.wikipedia.org/wiki/Reverse_Polish_notation),
que lerá os digitos pressionados em um teclado de matrix 4x4.

Os cálculos seram feitos usando [BCD](https://en.wikipedia.org/wiki/Binary-coded_decimal) para a facilidação do mesmo.
